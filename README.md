# bePm — AI 辅助项目排期管理

用自然语言描述项目，AI 自动解析任务、推断依赖、生成 DAG 拓扑图。描述进展，自动更新进度并分析风险。像聊天一样管理项目排期。

## 效果预览

打开应用，左侧输入项目描述：

> 开发一个电商平台，12月31日上线。数据库设计2天（后端），API设计1天（后端，依赖数据库），后端开发20天（依赖API设计），前端开发15天（依赖API设计），联调测试5天（依赖后端和前端），部署上线1天。

AI 几秒钟生成 DAG 排期图——所有任务节点、依赖关系、关键路径、最早最晚时间一目了然。

## 快速开始

```bash
# 1. 安装依赖
cd backend && pip install -r requirements.txt

# 2. 配置 LLM（~/.claude/settings.json）
# 支持 Anthropic / OpenAI / DeepSeek 等任何兼容接口

# 3. 启动
# Windows：双击 start.bat（自动打开浏览器）
# 其他：cd backend && python main.py

# 4. 打开 http://127.0.0.1:48090
```

## 怎么用

### 创建排期

1. 点「+ 新建项目」
2. 用自然语言描述项目——有什么任务、谁来做、要多久、什么顺序
3. 选截止日期，点「自动排期」
4. AI 生成 DAG 图，标注关键路径和缓冲区

### 更新进展

输入任何进展描述，AI 自动判断意图并执行：

- `数据库设计完成了` → 更新进度
- `把 task_3 改成中文名` → 批量改名
- `在 API 设计和后端开发之间加个代码评审，2天` → 新增节点 + 调整依赖
- `删除 task_4` → 移除节点
- `让前端开发依赖数据库设计` → 添加依赖

每次更新前会预览变更计划，确认后执行。

### 标签分组

给节点打标签（如 `backend`、`frontend`、`P0`），点击 DAG 顶栏标签即可按维度聚合成大节点——看后端整体进度、团队分布、优先级视图。

### DAG 交互

- 拖拽节点调整布局，滚轮缩放
- 点击节点查看详情 / 编辑 / 删除
- 拖拽面板边缘调整三栏宽度
- 节点颜色：青绿=完成，紫色=进行中，灰色=未开始，琥珀=延迟，红色=阻塞
- 粗黑边框 = 关键路径节点

### 对话模式

也可以用 [Claude Code](https://claude.ai/code) 加载 `agent.md`，在终端里对话式管理项目：

```
你：帮我排期一个App开发项目...
PM Agent：[自动调用 API 创建排期，展示 DAG 和风险分析]

你：UI 设计完成了
PM Agent：[更新进度，检测到关键路径偏移，提示风险]
```

## 支持的数据源

| LLM 后端 | 配置方式 |
|----------|---------|
| Anthropic | 默认，设置 API Key 即可 |
| OpenAI / DeepSeek / 通义千问 | 设 `LLM_SDK_TYPE=openai` |
| 任意 CLI 工具 | 设 `LLM_PROVIDER=cli` |

## 更新 Prompt

所有 LLM Prompt 以 `.md` 文件存放在 `backend/prompts/`，直接编辑即可自定义 AI 行为，无需改代码。
